# 用户归属与飞书“用户查询”

管理员可先在本机管理后台的「用户归属」栏目按完整姓名建立档案，勾选其名下平台普通用户，不需要飞书成员提前发起查询。新式姓名档案在当前平台管理员与目标群范围内唯一；既有按飞书身份保存的旧归属记录仍可读取，不会自动迁移或删除。

## 使用步骤

1. 管理员点「读取平台用户与查询申请」，选择「新建归属姓名」，填写唯一完整姓名，按用户名、邮箱或平台用户 ID 筛选并勾选平台普通用户，点「保存此姓名的用户归属」。即使显示“0 个已登记飞书身份”也能保存。搜索只筛选页面，不清除搜索结果外已勾选的账号。
2. 要查询的人须在**已绑定的目标群**中 @机器人，打开机器人私聊菜单并点击「用户查询」。首次点击会登记飞书稳定身份，机器人私聊回显从飞书取得的显示名与身份摘要；若当前无法取得姓名，会明确写“暂未取得”。显示名不是实名证明，**不会自动与同名档案绑定或展示账号**。
3. 管理员在后台「待核对／已绑定飞书成员」选择该申请，借可信渠道核对本人及身份摘要，再在「将选中成员绑定到姓名档案」明确选择已有档案，确认保存。每个姓名档案在同一管理员与目标群范围内至多绑定一个飞书身份；需要更正绑定时，仍须管理员再次核对并明确保存。旧式已绑定身份保持原归属，不因同名自动改绑。
4. 绑定成功后，成员从指定群再次 @机器人并在私聊点击「用户查询」，机器人直接按当前余额升序私聊发送**该稳定飞书身份所绑定**的账号、邮箱、用户 ID、余额与状态，**无需输入姓名**。若管理员尚未绑定，继续返回显示名与待核对提示，不接受成员自行输入别的姓名查询。
5. 管理员可从「归属档案」下拉框选已有姓名调整勾选。取消全部勾选并保存会保留档案，但查询结果为空。余额每次查询时重新从平台只读获取。

管理员点「读取平台用户与查询申请」时，管理端还会尝试从**当前已绑定目标群**读取成员显示名，用完整身份摘要精确对应已登记的人；下拉框优先显示“当前群显示名”，同时保留短身份摘要区分同名。当前群显示名只用于展示，不会重写旧归属记录，也不能单独作为绑定凭据。读取失败、成员离群或权限不足时，界面会标明原因；请让该成员把机器人私聊「用户查询」回复中的身份摘要转述给管理员，与下拉框中的同一摘要核对，不要按群消息顺序或同名猜身份。读取当前群成员名需要应用的 `im:chat.members:read` 权限、机器人在目标群内且权限已发布生效；开通权限属于飞书开放平台配置，不会由本机代码自动操作。

## 本机记录、草稿与恢复

- 正式归属保存在当前 Windows 用户应用数据目录的 `user-ownership/ownership.journal`。它是加密追加日志：每次成功保存都会追加完整档案快照及时间，不覆盖旧快照；既有旧格式记录继续读取。管理页“最近归属修改记录”显示最近 100 条摘要，旧格式记录可能没有精确保存时间。完整加密快照仍留在原日志中。
- 新版在填写姓名、搜索词和勾选平台用户后约 350 毫秒把草稿加密暂存到 `user-ownership/ownership-drafts.journal`；重开后点击「读取平台用户与查询申请」会恢复当前管理员/目标群范围内的未保存草稿。正式保存前会再次等待草稿安全落盘，正式保存成功后清除待保存标记。暂存失败时界面明确提示保持窗口打开，不把草稿当作已正式保存。**旧版窗口在新版加载前的未保存勾选无法由新功能追溯生成，切换前须人工确认其内容。**
- 已绑定成员每次查询，会在 `user-ownership/query-audit.journal` 加密追加：稳定身份及登记时保存的显示名、目标群、管理员范围、绑定档案姓名、时间、成功/错误及匹配用户数。管理页只显示当前范围最近 100 条和身份摘要；不保存查询当时的余额或邮件/消息正文。审计先安全落盘，失败时不返回查询资料。匹配到不代表私聊最终送达，显示名也不证明姓名归属。未绑定的申请只写入归属登记日志，不产生余额查询审计。
- 查询审计文件上限 8 MiB/20000 条，草稿文件上限 4 MiB；达到上限或文件损坏会停止对应写入并提示保留原件，不会自动删除历史。需管理员在受控备份/恢复验证后另行归档，不能直接清空文件。上述文件、备份和 Chromium 会话都不得加入 Git。Windows `safeStorage` 密文只适合同一 Windows 用户环境，不是跨电脑可恢复备份。
- 2026-11-05 对原有归属日志做了同机副本，前后 SHA-256 一致；这只证明字节复制一致，**未完成独立环境解密恢复演练**。原件与副本均保留，不据此承诺跨机恢复。若旧窗口仍有未保存的勾选，请不要在核对前刷新或重启。

## 接口与边界

- `GET https://max.cheapi.cc/api/v1/auth/me` 核验当前 Bearer 管理员和账户；`GET /api/v1/admin/users?page=N&page_size=100` 串行读取用户列表。平台分页响应使用 `items` 与 `total`；重复 ID、总数变化、空缺页或超过 50 页/5000 条会拒绝展示。没有写入平台用户资料的请求，也不会创建账号或令牌。
- 登记是**申请门槛**，不是本人身份核验；显示名可重名、可变化，不能作为权限键。权限只来自管理员明确保存的稳定飞书身份→姓名档案绑定；未绑定成员不能通过输入别人的姓名取得账号。旧式已绑定记录仍按原稳定身份一键查询，不自动迁移。管理员对真实身份的人工核对质量仍是安全边界，不能把本地测试称为实名认证。
- 归属、绑定与登记只保存在当前 Windows 用户的本机加密日志中，按平台管理员账户和目标群隔离；损坏或无法解密时功能关闭并保留原件。旧范围不在新管理员或新群显示。档案改动后，已绑定身份查询会实时读取该档案当前勾选的账号；读取期间若绑定或档案变化，拒绝使用旧结果。
- 机器人只接受指定群发起的短时私聊会话，结果只发给发起人的飞书身份；群聊不会发邮箱或余额。真实飞书客户端与跨重启使用仍需管理员在授权加载新版后验收；隔离夹具不证明线上查询成功。
