# 管理员分组设置与用户专属倍率

版本：本地增量 `group-settings-v2`（账号表单与侧边栏），基于 `9fc7ed5`；核对日期：2026-10-30。

## 目标与范围

只有本机已绑定的飞书管理员可使用第三个菜单“分组设置”。普通群成员仍只看见用户注册、令牌创建；服务端也拒绝伪造入口、卡片、发送者或过期会话。目标用户以正整数平台ID或完整邮箱定位，不按模糊昵称猜测。邮箱必须唯一精确匹配；先在卡片核对用户ID、邮箱和用户名。

本功能设置每个用户的专属分组倍率，以及是否允许使用某个专属分组。在用户已启用“限制公开分组”的情况下，也可以调整其公开分组勾选；不切换这个全局开关。公开分组原本全部开放时，保持全部开放。其他用户、角色、余额、密码、并发和未发布分组保持不变。

## 管理员操作

1. 在本机侧边栏“管理配置”完成平台管理员授权，然后切换到“分组设置”。
2. 点击“读取倍率配置分组”。这与侧边栏“令牌分组”独立，读取全部启用的标准分组，包含专属分组，排除停用或订阅类分组。
3. 为需要出现在飞书中的分组填写菜单显示名称，点击“保存并发布倍率配置分组”。留空不发布；同一账号下别名不得重复。此操作只保存本机别名，不改平台用户数据。
4. 在已绑定群 @机器人，再由已绑定管理员私聊选择“3. 分组设置”。连接、平台账号匹配、群策略和管理员绑定仍须有效。
5. 在卡片的“用户账号”输入框填写完整邮箱或用户ID，点击“查询用户分组”，无需另发账号聊天消息。确认是需要修改的用户，再逐页填写分组卡片：每页5组，允许/不允许选择会更新分组使用权；倍率至少0.001，最多3位小数；倍率留空恢复平台默认。
6. 点击“保存本页，下一页”，到最后一页后进入核对。返回上一页不会自动保存当前页尚未提交内容；点击“修改”会保留已经提交的草稿。
7. 点击“确认保存”才发起一次更新（包括核对页列出的分组授权变化）。仅在平台回读的完整分组授权、公开限制模式与专属倍率一致后，私聊回复“设置成功”。只发给管理员，不在群内展示目标用户信息。

本机侧边栏：管理配置（平台授权、飞书连接与群策略）、令牌分组（客户菜单别名）、分组设置（专属倍率目录与记录）、令牌记录、注册记录。切换只显示目标栏目，保留非敏感表单草稿；离开页面清空App Secret输入和已显示的令牌密钥，阻止迟到响应回填密钥。侧栏不改变功能权限。

2026-10-31新增第六栏目[操作日志](admin-operation-log.md)，可查本机发布等操作的成功/失败、阶段与错误编号；保存按钮旁同步显示结果，无需滚回列表顶部。名称重复会显示明确INPUT错误并保留草稿。

卡片无法显示时可回复“重新显示表单”；不提供通过普通聊天“确认”绕过核对卡片的路径。回复“取消”会丢弃会话。会话沿用10分钟时效和每身份5分钟最多3次入口限制。

## 未知结果与维护

- 修改前先将操作编号、目标用户ID、修改项和前后配置写入独立账本，写入失败不调用更新接口。
- 超时、响应不明确、成功回执写入失败或回读不符时，不回复成功，不自动重试，也不自动回滚。
- 本机“分组设置记录”展示当前管理员最近100条操作；存在pending/unknown会暂停新的分组设置，不影响已有注册/令牌业务的独立账本。
- “仅回读平台核对”只发GET；一致后标记成功，不一致保持保护。若已在平台人工核对并处理，可选择“已人工核对，解除保护”，还需确认对话框。`reviewed`不等于设置成功。
- 新账本和别名保存在业务数据根的 `group-settings/` 子目录，不能提交仓库。该账本包含配置前后值，属于本机管理资料；沿用现有追加式存储，不宣称为新的系统级权限隔离或安全认证。
- 切换版本需正常退出旧业务实例，再启动并手动连接；不重新保存飞书Secret、不清除原绑定。源码修改不会热更新已运行进程。

## 接口契约与证据

固定平台源为 `https://max.cheapi.cc`，沿用本机平台管理员Bearer授权，`credentials: omit`，禁止重定向，单请求超时30秒；不记录令牌、Cookie、响应正文或真实邮箱。仅提炼协议，自行实现，没有复制第三方页面、组件或业务代码。

| 方法与路径（相对 `/api/v1`） | 用途与字段 |
| --- | --- |
| GET `/auth/me` | 当前授权ID与`role=admin`校验 |
| GET `/admin/groups?page=N&page_size=100` | 分页读取`items,total`，使用`id,name,status,subscription_type,is_exclusive,rate_multiplier,platform`；最多20页，重复ID、总数变化、不完整分页拒绝 |
| GET `/admin/users/{id}` | 读取准确用户，使用`id,email,username,role,status,allowed_groups,restrict_public_groups,group_rates` |
| GET `/admin/users?page=N&page_size=100&search={encodedEmail}` | 完整邮箱查询，最多5页；只接受唯一精确邮箱匹配 |
| PUT `/admin/users/{id}` | 严格只允许`allowed_groups,restrict_public_groups,group_rates`；目标用户与核对页绑定，更新前再次检查管理员、会话和原配置 |
| GET `/admin/users/{id}` | 更新后或人工触发的只读核对；不一致保持unknown |

`group_rates`键为分组ID，值为倍率；值为null表示清除专属倍率。空倍率映射可能因服务端`omitempty`省略；`allowed_groups:null`按空集合处理，缺失访问模式或身份字段仍拒绝。保存时合并保留其他分组倍率和授权；不改变全局分组默认倍率。业务失败不自动重试；只在管理员主动刷新时重新读取，不对上游加并发。
