# 飞书机器人 · 令牌与注册助手

Windows 桌面管理端 + 飞书长连接机器人。群成员 @机器人后进入私聊菜单，选择「用户注册」「令牌创建」「用户查询」或「用户用量」。这是从既有项目独立导出的完整机器人源码，不需要账号池分析、MySQL或phpStudy。

## 完整说明书

**[从零搭建、密码与密钥配置、权限发布、群绑定、换机和排障完整手册](docs/setup-guide.md)**

首次配置请按完整手册操作；原机器人换电脑直接看 [迁移步骤](docs/migration.md)，继续使用同一个飞书应用和原群。手册详细说明每类凭据的来源、填写位置和保存要求，但不包含真实密码或密钥。

**浏览器说明：** 安装依赖和Electron运行时后，程序自带受限的Chromium平台登录窗口，无需安装Chrome或Codex的Browser插件。系统浏览器、Codex及其插件、旧登录态不随GitHub迁移；新电脑必须重新进行管理员授权和本机凭据配置。详见 [工具与浏览器对照](docs/setup-guide.md#1-新电脑需要什么浏览器能不能打开)。

## 新电脑快速开始

1. 访问本公开仓库，下载 ZIP 后解压到固定目录，或使用 Git 克隆；读取和下载不需要仓库访问授权。
2. 安装 [Node.js 24 LTS](https://nodejs.org/)（包含 npm）。目前主要验证 Windows 运行环境。
3. 双击 `install.bat`，等待两组锁定依赖以及 Electron 桌面运行文件安装、校验完成。下载单次超时5分钟，失败时明确提示，不会启动机器人。不要只下载单个启动脚本；不要复制旧电脑的 node_modules。
4. 双击 `启动飞书机器人.bat`，打开业务管理员窗口。**不是 `飞书连接诊断.bat`，后者只诊断连接，不能处理群业务。**
5. 按 [迁移步骤](docs/migration.md) 重新登录平台、保存同一个飞书应用的凭据、确认管理员及原群绑定、保存策略并连接。

**只切换运行电脑，不新建飞书应用或机器人，也不必仅因迁移发布新应用版本。旧电脑先正常退出服务，新电脑才允许连接；严禁两台同时处理正式申请。** 此次源码导出与上传不停止旧服务。

## 功能与约束

- 管理后台新增[渠道监控](docs/channel-monitor.md)：五个指定网址分别直观显示两项积分余额与三项剩余余额，成功后约半小时只读刷新，异常时按2/5/10/15分钟退避自动复查；各站可改名称，使用独立本机登录会话。每张卡片的登录账号、密码、加密保存并启用/暂停/清除在默认收起的设置中；管理员按需单独启用，登录失败即暂停，验证码和无已存凭据的失效登录仍需人工处理。读取不提交创建业务请求。站点组件与位置整理在[页面定位台账](docs/channel-workflows/README.md)。
- 新增[渠道授权](docs/channel-access.md)独立管理栏：按机器人账号与成员稳定标识预配置可见渠道、加密保存、撤销及本机只读预览。当前是隔离原型，尚未完成真实身份绑定或接入 CodexBridge、微信、AI；不会向外发送读数。
- 渠道监控另有默认收起的 QQ 邮箱提醒：五站按各自原单位独立与管理员自定阈值比较（旧配置默认为 2000），成功读取且低于阈值时每渠道/收件人同一低值区间只提醒一次；可选北京时间每日固定时分向全部收件人各发一封五站余额汇总，高于阈值也发送，过期/失败读数标未取得。首次升级默认不启用每日汇总。另有手动测试邮件。授权码只在本机加密保存，真实定时投递待验收。详见[渠道监控说明](docs/channel-monitor.md#低余额邮件提醒)。
- 新增管理员专用菜单「分组设置」：独立读取/命名发布倍率分组，选择准确平台用户后分页设置专属倍率与分组授权，核对提交并回读一致才报告成功；普通群成员不可使用。见 [使用与验收说明](docs/group-settings.md)。本地增量已通过隔离测试，真实用户修改及在线版本切换待验收。
- 管理后台「用户归属」可先按完整姓名建档并勾选平台普通用户；未保存表单本机加密暂存，正式归属保存完整修改快照。目标群成员首次 @机器人并点「用户查询」时，机器人私聊回显飞书显示名和身份摘要，管理员核对后明确绑定姓名档案；已绑定成员再次点击即直接查自己的当前余额，无需输入姓名。显示名不作权限凭据，未绑定者不能按姓名查看其他档案；查询有本机加密审计。旧窗口未保存草稿不能靠新版自动找回。见 [用户归属说明](docs/user-ownership.md)。
- 「用户归属」的登记成员列表会在权限允许时优先显示当前目标群飞书显示名，并保留身份摘要以区分同名；缺少群成员读取权限时明确提示用机器人私聊摘要核对，不会凭截图猜测身份。见[成员姓名说明](docs/feishu-member-names.md)。
- 「用户归属」下方另有[每日用量群表](docs/daily-usage.md)：按当前归属账号的用户实付金额生成最近 3 天滚动表，逐邮箱显示，仅向原绑定群发送。管理员先预览、填写北京时间每日时刻并显式启用；正常发布每份归属卡每天最多更新一次，整档移除有隐私优先脱敏例外。未设置时间的旧启用配置不再自动群发。本机历史仍约每小时只读采样。群消息结果不明时停发待核对；已保存的群卡不会因暂停而删除。目标群成员另可 @机器人后在私聊菜单点「用户用量」，仅按已核验身份查询本人归属账号的今天用量，历史两日仅使用已固定快照；不在群里公开这次按需查询结果。新功能本地已实现，正式实例尚未重载。
- 管理端另有「用量统计」历史周表：从本机已采集的加密快照按月、周、所属人筛选，逐账号显示每天用量及周合计，不受群卡片三天展示限制；缺日不会当作零。管理员可手动补采当前月已结束日期，按当前归属回填并标明来源，不自动发群。见[每日用量说明](docs/daily-usage.md#管理端历史周表)。
- 本机历史采样与群卡片发布分别运行：管理员授权、原目标群绑定和归属档案就绪时，约每小时只读采样并加密保存；**群卡片未启用也会采样，不会因此向群发消息**。次日补读昨天，按当前归属回填的快照明确标注来源；停机超过一天的空档仍须受控补采。
- 「用量统计」可自选日期导出当前归属人或全部归属人的 Excel `.xlsx`，全部归属人位于同一张可筛选明细表；导出仅使用本机已有快照，保留未记录、进行中和回填标记，不发群、不补采。
- 管理后台「账号管理」可为平台账号配置多条一次性的调度开关切换计划；每条选择两个账号、先开后关或先关后开，并填写两次完整的北京时间，可跨日、跨月。结果不明不会自动重试或继续第二步。见 [账号调度说明](docs/account-schedule.md)。
- 原群全体成员可申请；只展示管理员命名并发布的客户分组。
- 令牌：选择分组、必填额度、确认一次，成功后仅给发起人私聊发送平台网址和密钥。
- 注册：卡片填写邮箱、专用密码、用户名、并发数1–50，初始余额只能选0/1/5/10；固定普通用户，核对后再确认提交。
- 管理员端可查看创建记录、安全错误编号；不同业务独立账本，未知创建结果暂停而不自动重试。
- 注册与令牌创建失败会在发起人私聊给出[可理解的安全原因](docs/platform-error-messages.md)，例如邮箱已存在；结果不明仍要求先核对，不转发平台原始错误或重复创建。
- 本版本只处理一个明确绑定的群；扩展入口和业务流程分离，见 [结构说明](docs/architecture.md)。

## 命令行

```powershell
npm ci --no-audit --no-fund
npm run deps:bot
npm run runtime:install
npm run check
npm test
npm start
```

`npm run test:ui` 使用虚构接口和隔离数据目录运行 Electron 管理页回归；`npm run diagnose` 打开独立诊断工具；`npm run customer` 打开无管理员登录按钮的客户工作台。

根 `package-lock.json` 锁定 Electron 42.4.0；`key-tool/package-lock.json` 锁定飞书 SDK 1.76.0 及其依赖。两次 `npm ci` 都需要执行，再串行执行 `npm run runtime:install`。新版 Electron 的 npm 包安装成功不等于桌面二进制已下载；测试和命令行启动会先检查运行文件，缺失时拒绝隐式下载。未包含已安装依赖、运行时二进制或 exe 安装包；首次安装需要网络。

## 数据和秘密不在 GitHub

本机运行后会在项目`本机数据/`生成可用Excel打开的创建记录CSV与变化轨迹（已排除Git，禁止随整项目分享）。权威账本仍在应用数据目录；见[表格使用说明](docs/local-record-tables.md)。

本仓库是**程序迁移，不是历史业务数据备份**。不包含 App Secret、平台登录态、Cookie、真实密码/密钥、用户数据、创建记录或群策略。它们位于管理员电脑应用数据目录，参见 [安全说明](SECURITY.md)。

新电脑须重新授权。Windows 加密文件不能当作跨机可解密配置直接复制。原电脑和原件保留，历史记录也不会因为克隆仓库自动出现在新电脑。历史 pending/unknown 必须先核对；本仓库没有跨机账本/历史回执迁移器。

## 长期运行与验收边界

2026-10-31起，业务程序已增加[自动连接与断线恢复](docs/auto-reconnect.md)：启动后恢复连接，主进程每5秒检查状态，失败后退避持续重试；主动断开可暂停。仅恢复飞书通道，不自动重试任何业务创建或更新。

2026-11-06 增加 Windows 旧连接锁恢复：电脑关机或程序异常退出后，启动时会在确认旧进程不存在、独占锁文件并保留原件后自动恢复；其他活跃进程、权限不足或损坏锁仍保持保护。无需因残留锁重新保存密钥或重新绑定群。

电脑须开机、不休眠、网络正常，管理工具显示「已连接」。锁屏通常不影响，注销/休眠/退出应用会中断。尚未实现 Windows 服务、自动开机连接或跨机协调；不要把加到启动目录等同于飞书已连接，凭据过期仍需管理员处理。

导出前版本的267项单元/集成测试、47份业务脚本语法、46项Electron隔离检查已通过；本仓库独立安装后的实际验证范围见 [交付记录](docs/release.md)。**本地测试、长连接在线不代表真实手机表单渲染、外部成员可见范围或平台注册成功已验收。**
