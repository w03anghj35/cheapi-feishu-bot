# 注册与令牌创建失败提示

更新日期：2026-11-02。

机器人只在发起人的私聊返回可理解的原因、错误编号和操作编号。平台响应可能回显密码、令牌或请求内容，因此不转发原始 `message`、`msg`、`error` 或完整响应，而是把明确识别的错误翻译成固定文案。

| 平台明确拒绝的类型 | 用户看到的重点 |
| --- | --- |
| 邮箱已存在或已注册 | 这个邮箱已经注册，可换邮箱；已有账号应直接登录 |
| 用户已存在 | 请确认邮箱或联系管理员核对 |
| 用户名被使用 | 换用户名后重新发起 |
| 令牌分组不可用 | 重新选择分组或联系管理员 |
| 令牌额度不符合要求 | 调整额度 |
| 管理员余额不足 | 联系管理员处理 |

未识别的平台拒绝给出安全的通用说明及 HTTP 状态，不猜测根因。提交前的授权、输入、网络或存储问题分别说明“未提交”。一旦请求可能已发送，但网络超时、回执不完整或本机保存失败，机器人必须说明“结果尚未确认、可能已创建”，保留待核对记录，不自动重试。不能仅凭网络错误断言创建失败。

接口边界沿用平台固定源 `https://max.cheapi.cc`：`POST /api/v1/admin/users`、`POST /api/v1/keys`，Bearer 认证、`credentials: omit`、拒绝重定向，单请求 30 秒。只在非 2xx 或业务 `code != 0` 时读取有上限的错误体（最多 8192 字节），只识别有限字段中的短消息并映射为内部枚举；绝不持久化原文。明确的 400/409/422 等拒绝或已识别的业务错误可标记失败，结果不明仍保持 unknown。令牌失败诊断和注册账本只保存安全错误类别，管理员可以按操作编号核对。

本轮使用合成响应和虚构账号验证 409、200 内业务错误、超大错误体、密码回显、明确拒绝、超时、重复点击及重新打开后的状态；不向真实平台提交测试账号或令牌。真实平台未来变更文案时，未知错误回退为通用提示，不会自动展示未经审查的原文。
