# 批量分组调价（管理员专用）

本机管理端侧边栏「批量分组调价」只处理平台当前**启用的标准分组**和**活跃普通用户**。点击「只读查询当前分组与用户倍率」会列出分组默认倍率、每位用户在 `allowed_groups` 中明确勾选的分组及其有效倍率；没有专属 `group_rates` 覆盖时标为「默认」。查询、搜索、全选和勾选都不修改平台。

先勾选分组，再勾选用户；「全选」针对本次完整读取的所有活跃普通用户，不随关键词筛选缩小。输入关键词可只显示匹配用户，再取消其中某人的勾选；其他隐藏用户的勾选保持不变，页面显示总勾选数。方向下拉选择「上调」或「下调」，输入固定幅度，如 `0.2`：原有效倍率 `1.8` 上调后预览 `2.0`。只支持正数、最多三位小数；精确按千分位整数运算。目标倍率低于 `0.001` 或超出本次允许上限时跳过，不静默截为边界值。

用户较多时可点击「读取文档识别邮箱」，选择本机 TXT、CSV、XLSX、DOCX、PDF（含扫描版）或 PNG/JPG 名单。支持从多列或段落提取完整邮箱，以当前读取的活跃普通用户完整邮箱（不区分大小写）精确匹配；找不到或同邮箱对应多人的条目不自动勾选。系统先列出匹配人和未匹配邮箱，管理员逐项核对并可取消候选勾选，再明确点击「勾选文档中的用户」或「取消勾选文档中的用户」。若先全选全部用户，通常选择取消名单中的用户；未全选时通常选择勾选名单中的用户。这两个按钮只改变本页选择，不会预览、提交或修改价格。DOCX、PDF 和图片候选默认全不勾选，必须由管理员逐项确认；图片/扫描版 PDF 的本机 OCR 可能错认字符。旧版 DOC/XLS 应先转为 DOCX/XLSX；其他未知格式拒绝读取。文件仅在本机管理员主进程解析，不上传平台；窗口不会收到完整文件路径。读取/取消文件选择失败时原勾选不变。

文件读取有大小、行数、页数和耗时限制，超过会明确拒绝，不返回不完整名单。XLSX 只读第一个工作表。PDF 按页先提取文字；没有完整邮箱或检测到栅格图片的页面再做本机 OCR 并去重。混排文件、低清晰度图片仍可能漏识或错识，须核对原文件及候选。菜单所称“文档”仅涵盖上述格式，旧版 DOC/XLS 等不保证识别。

原价格快照自完成读取起超过 10 分钟不能再预览。点击顶部重新读取会立即使旧预览失效；若还是同一个管理员，新目录中的用户 ID 与完整邮箱都一致、分组 ID 仍存在，页面会保留这些勾选，并提示不匹配而取消的项数。读取失败时原勾选仅在当前窗口暂存，下一次成功读取后才核对恢复；授权账户变更、批量提交或重开窗口不恢复旧选择。读取文档的候选结果在重新读取或授权变化后清除，需重新核对；即使恢复勾选，也必须再做一次新的预览与确认。

「已勾选」只认用户的 `allowed_groups` 显式包含该组 ID。公开分组在未限制模式下可能对用户可用，但没有逐项勾选的公开组不参加本功能；未拥有所选组的用户跳过，**不会替他新增授权**。批量更新只改变被选中、用户已拥有组的 `group_rates` 倍率覆盖；原 `allowed_groups`、公开组限制模式和所有未选分组倍率保持不变。

先点「预览每位用户的新倍率」查看每项旧值、新值和跳过原因。修改用户/分组勾选、方向或幅度会让旧预览失效。只有再次明确确认后才开始逐用户写入；这不是一次原子事务，已成功的用户不会因后续失败自动回滚。每位用户发请求前写入独立 Windows 加密尝试记录，单次 PUT 后完整 GET 回读一致才标成功。请求或回读结果不明时停止后续用户，不自动重试；「调价记录」仅提供只读回读核对，一致才确认成功，不提供手工绕过保护。旧的单用户分组设置入口与本功能相互阻断，避免两边同时写。

预览最多接受 5000 个“所选用户×所选分组”组合；超过会提示拆成小批次。预览列表一次先显示 200 项，可继续展开，但顶部始终列出完整修改/跳过数量。确认弹窗再次说明本次完整覆盖的项数，不能把屏幕上尚未展开的部分误认为不提交。大量客户会逐个读取详情和回读，可能需要数分钟；读取进度显示人数。当前价格只按您主动读取的平台时点展示，不会在后台悄悄写入。

## 接口与边界

- 只读分组：`GET /api/v1/admin/groups?page=N&page_size=100`；只展示 `status=active` 且 `subscription_type=standard` 的分组。平台不在此范围内的停用组或其他订阅组不参加调价。
- 只读用户目录：`GET /api/v1/admin/users?page=N&page_size=100`，分页校验总数、重复 ID 和目录变化；用户详情 `GET /api/v1/admin/users/{id}`。上限为本次最多 500 位活跃普通用户、100 个所选分组；超出明确拒绝不完整目录。读取大量用户可能需要数分钟，页面按已读取人数显示进度。
- 写入：仅 `PUT /api/v1/admin/users/{id}` 的白名单 `{allowed_groups,restrict_public_groups,group_rates}`，本机原管理员 Bearer 认证、每次 GET `/api/v1/auth/me` 核验账户与管理员角色。提交前复查分组目录、目标用户原配置及当前身份，单次 PUT 后 GET 用户详情核对预期；不使用 Cookie 身份，不提交密码、余额或角色字段。现有单请求网络上限 30 秒；单批最多执行约 10 分钟，到时停在未开始的用户。
- 结果不明：平台回执成功不等于倍率持久化成功。公开上游实现存在用户字段更新成功、倍率同步未完成的路径，因此本工具必须以实际 `group_rates` 回读为准。旧平台站点的实际部署行为仍需现场验收，不能仅凭本地隔离测试证明生产写入无风险。

新功能在源码中实现后仍须重新启动正式管理端才会加载。未经管理员逐项核对，不在真实用户上做测试写入；服务运行、页面出现和本地测试通过都不等于平台价格已修改。
