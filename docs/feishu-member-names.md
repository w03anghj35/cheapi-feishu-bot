# 创建记录显示飞书成员名字

更新日期：2026-10-31。

## 用户界面

令牌记录和注册记录优先显示飞书接口返回的成员名字，例如飞书账号自身显示为“组织9…”时直接展示该名字。不是平台用户名，也不从用户聊天正文、注册表单或邮箱猜测发起者。

- 新创建：将读取到的名字作为创建时快照保存，标注“创建时飞书姓名”。
- 旧记录：原记录仅存身份摘要，无法逆推出名字。按当前绑定群成员的open_id计算同一摘要并匹配后，在界面补充“当前飞书姓名”，不改写历史账本；离群、换应用或无匹配时不补猜。
- 姓名获取失败显示“飞书姓名未获取”，仍保留稳定身份标识以便核对，不阻断原有创建业务。
- 名字可能重名或改名，因此主标题显示名字，次行提供短身份标识，详情保留完整摘要用于同名区分。
- 令牌记录支持按名字搜索。姓名用于显示与检索，权限、去重、个人额度和群额度始终使用稳定身份；改名不重置额度，同名不合并用户。
- 操作日志继续不收集姓名、成员列表或接口原文；姓名快照属于本机业务账本，不能上传源码仓库。
- 「用户归属」的已登记成员下拉框也优先显示当前目标群的显示名，并保留短身份摘要；按存储的完整 SHA-256 身份摘要匹配群成员 open_id，不以姓名或列表顺序匹配。没有权限或成员不在群时只显示登记时姓名或“飞书姓名未取得”，并提示用机器人私聊摘要人工核对。当前群姓名是只读临时投影，不写入归属账本。

## 飞书配置

需要应用身份权限 `im:chat.members:read`（查看群成员），应用机器人必须在被查询的群内。2026-10-31只读核对时，应用仅有消息发送、单聊读取和群@读取三项权限，尚未开通查看群成员。2026-11-06 经管理员明确同意，已在飞书开发者后台开通该应用身份权限；权限页显示“已开通”，版本页显示“当前修改均已发布”且新建版本的“权限变更”为空，因此没有额外创建无关版本。管理员随后反馈「用户归属」下拉框已出现飞书名字，管理端成功读取 2 个已登记身份且不再提示姓名读取失败。没有重新登记成员或更改身份绑定。

开通后按飞书后台要求发布生效，再加载本地新代码；在令牌/注册记录点击刷新。首次读取最多等待2秒，若后台仍在加载，可稍后再刷新。权限与实际成员名字的可用性要现场验证；外部群受平台限制，不承诺能读所有外部联系人或任意“组织名称”。

管理页读取时会返回“当前群成员姓名读取被拒绝／未连接／仍在读取”等状态，供管理员核对。2026-11-06 的用户反馈确认当前两条登记已有可读姓名，但这不等于法律意义上的实名认证；同名和改名仍须核对稳定身份摘要。

## 接口与限制

- 官方接口：GET `https://open.feishu.cn/open-apis/im/v1/chats/{已绑定群ID}/members`。
- 鉴权：沿用官方Node SDK的应用凭据/tenant_access_token；不读取或展示Secret/token。
- 参数：`member_id_type=open_id`、`page_size=100`，按`has_more`和`page_token`继续。实际条数可能小于或大于page_size，不能按短页提前停止。
- 只取`member_id_type,member_id,name`用于摘要与显示名；忽略tenant_key等无关字段。仅查询当前已绑定群，不扫描全部通讯录或其他群。
- 最多20页/5000个成员、8秒分页时间预算；每次等待最多2秒，多个调用共享同一个后台任务。SDK底层请求可能仍在完成中，不重复并发请求；完整成功后缓存5分钟，失败冷却60秒，不立即重试或绕限流。
- 应用/群/SDK客户端变更使缓存失效，迟到结果不可覆盖新范围。缓存只在内存，业务快照在现有本机账本。
- 每个名字最多100字符，拒绝控制字符，页面以纯文本呈现。未完成分页不使用部分结果，数据冲突、重复ID、重复分页标记拒绝。

来源：2026-10-31浏览器读取飞书官方[获取群成员列表](https://open.feishu.cn/document/server-docs/group/chat-member/get)（页面更新日期2024-10-30），并核对本机锁定SDK的`im.chatMembers.get`实现。未引入新依赖或复制第三方实现。
