# 飞书机器人 · 令牌与注册助手

Windows 桌面管理端 + 飞书长连接机器人。群成员 @机器人后进入私聊菜单，选择「用户注册」或「令牌创建」。这是从既有项目独立导出的完整机器人源码，不需要账号池分析、MySQL或phpStudy。

## 完整说明书

**[从零搭建、密码与密钥配置、权限发布、群绑定、换机和排障完整手册](docs/setup-guide.md)**

首次配置请按完整手册操作；原机器人换电脑直接看 [迁移步骤](docs/migration.md)，继续使用同一个飞书应用和原群。手册详细说明每类凭据的来源、填写位置和保存要求，但不包含真实密码或密钥。

**浏览器说明：** 安装依赖和Electron运行时后，程序自带受限的Chromium平台登录窗口，无需安装Chrome或Codex的Browser插件。系统浏览器、Codex及其插件、旧登录态不随GitHub迁移；新电脑必须重新进行管理员授权和本机凭据配置。详见 [工具与浏览器对照](docs/setup-guide.md#1-新电脑需要什么浏览器能不能打开)。

## 新电脑快速开始

1. 使用获授权的 GitHub 账号访问本私有仓库，下载 ZIP 后解压到固定目录，或使用 Git 克隆。
2. 安装 [Node.js 24 LTS](https://nodejs.org/)（包含 npm）。目前主要验证 Windows 运行环境。
3. 双击 `install.bat`，等待两组锁定依赖以及 Electron 桌面运行文件安装、校验完成。下载单次超时5分钟，失败时明确提示，不会启动机器人。不要只下载单个启动脚本；不要复制旧电脑的 node_modules。
4. 双击 `启动飞书机器人.bat`，打开业务管理员窗口。**不是 `飞书连接诊断.bat`，后者只诊断连接，不能处理群业务。**
5. 按 [迁移步骤](docs/migration.md) 重新登录平台、保存同一个飞书应用的凭据、确认管理员及原群绑定、保存策略并连接。

**只切换运行电脑，不新建飞书应用或机器人，也不必仅因迁移发布新应用版本。旧电脑先正常退出服务，新电脑才允许连接；严禁两台同时处理正式申请。** 此次源码导出与上传不停止旧服务。

## 功能与约束

- 原群全体成员可申请；只展示管理员命名并发布的客户分组。
- 令牌：选择分组、必填额度、确认一次，成功后仅给发起人私聊发送平台网址和密钥。
- 注册：卡片填写邮箱、专用密码、用户名、并发数1–50，初始余额只能选0/1/5/10；固定普通用户，核对后再确认提交。
- 管理员端可查看创建记录、安全错误编号；不同业务独立账本，未知创建结果暂停而不自动重试。
- 本版本只处理一个明确绑定的群；扩展入口和业务流程分离，见 [结构说明](docs/architecture.md)。

## 命令行

```powershell
npm ci --no-audit --no-fund
npm run deps:bot
npm run runtime:install
npm run check
npm test
npm start
```

`npm run test:ui` 使用虚构接口和隔离数据目录运行 Electron 管理页回归；`npm run diagnose` 打开独立诊断工具；`npm run customer` 打开无管理员登录按钮的客户工作台。

根 `package-lock.json` 锁定 Electron 42.4.0；`key-tool/package-lock.json` 锁定飞书 SDK 1.76.0 及其依赖。两次 `npm ci` 都需要执行，再串行执行 `npm run runtime:install`。新版 Electron 的 npm 包安装成功不等于桌面二进制已下载；测试和命令行启动会先检查运行文件，缺失时拒绝隐式下载。未包含已安装依赖、运行时二进制或 exe 安装包；首次安装需要网络。

## 数据和秘密不在 GitHub

本仓库是**程序迁移，不是历史业务数据备份**。不包含 App Secret、平台登录态、Cookie、真实密码/密钥、用户数据、创建记录或群策略。它们位于管理员电脑应用数据目录，参见 [安全说明](SECURITY.md)。

新电脑须重新授权。Windows 加密文件不能当作跨机可解密配置直接复制。原电脑和原件保留，历史记录也不会因为克隆仓库自动出现在新电脑。历史 pending/unknown 必须先核对；本仓库没有跨机账本/历史回执迁移器。

## 长期运行与验收边界

电脑须开机、不休眠、网络正常，管理工具显示「已连接」。锁屏通常不影响，注销/休眠/退出应用会中断。尚未实现 Windows 服务、自动开机连接或跨机协调；不要把加到启动目录等同于飞书已连接，凭据过期仍需管理员处理。

导出前版本的267项单元/集成测试、47份业务脚本语法、46项Electron隔离检查已通过；本仓库独立安装后的实际验证范围见 [交付记录](docs/release.md)。**本地测试、长连接在线不代表真实手机表单渲染、外部成员可见范围或平台注册成功已验收。**
