# 项目内创建记录表与变化轨迹

更新日期：2026-10-31。

## 保存位置与用途

项目根目录的`本机数据/`保存以下内容：

- `创建记录.csv`：Excel可直接打开的自动更新明细，UTF-8 BOM编码，中文表头。
- `创建记录.json`：同一份白名单字段及导出时间，用于逐项核对。
- `变化轨迹.jsonl`：首次收录与状态/内容变化的追加轨迹，含记录摘要；不覆盖过去变化。
- `创建记录快照.xlsx`：2026-10-31生成的格式化Excel快照，含筛选、冻结表头及日期格式。它不自动刷新，最新数据以CSV及其更新时间为准。

权威业务账本仍留在原Windows应用数据目录。项目中的表和轨迹是可读副本，编辑CSV/Excel不会修改平台或账本，也不能据此解除pending/unknown保护。不能把复制该文件夹等同完整业务恢复备份。

## 字段与更新

表格包括令牌创建、用户注册、分组设置：类型、时间、创建者名字及来源、状态、目标账号、用户名、分组、额度/余额/并发/倍率、权限、错误、交付状态、各类ID及操作编号。分组设置按每个修改分组一条明细，操作编号可能重复，明细编号唯一。

只导出明确字段，不复制完整payload、不解密回执，不含密码、App Secret、授权token或完整令牌密钥。姓名读取权限尚未开通时显示“姓名未获取”并保留稳定身份标识，不猜测名字。数据保留成功、失败及待核对，不只保留成功项。

业务记录变化后约300毫秒更新表格；启动、退出时同步，每60秒检查一次并补偿之前写入失败。操作日志栏目中可点击“立即更新记录表”“打开本机数据文件夹”，查看最后更新时间、明细数和错误。

Excel占用CSV或目录无权限时保留原表并显示未更新，不影响权威账本或已完成业务。请关闭占用文件再更新。JSON和CSV分开原子替换，意外中断时可能不是同一代，需以最后一次完整同步成功状态为准；这不是跨文件事务。

轨迹文件损坏、截断或超过20MB时保留原件，不自动删除/重建。来源记录缺失不会静默清空过去导出的表格。轨迹在启用前的首次记录只标“首次收录”，不伪造过去发生过的全部状态变化。以后状态变化通过操作编号与原业务账本关联核验。

## 隐私与版本控制

`本机数据/`已写入`.gitignore`，发布前检查也拒绝把该目录纳入提交。若手工打包或上传整个项目，仍应排除该文件夹；Git忽略不控制其他同步/分享工具。

启动时使用固定脚本准备目录ACL，只允许当前Windows用户、SYSTEM和Administrators；先设置并核验目录权限，再输出内容。没有修改全局PowerShell执行策略。拒绝符号链接导出目标，临时文件只在受限目录内生成并原子替换。

文件含账号和业务操作信息，应仅供管理员本机使用。若需要数据迁移或异地备份，应另行规划、保护并验证，不上传凭据或旧加密回执。
