# 保存反馈与本机操作日志

更新日期：2026-10-31。

## 保存并发布

本次现场只读核验发现旧版上方已显示“倍率配置分组已发布”，并非此次保存一定失败；按钮在长列表底部，上方唯一提示不在视口内，且等待期间只禁用按钮，没有说明。

新版“分组设置”的保存区吸附在视口底部，按钮旁显示：正在保存、等待秒数、成功时发布/隐藏数量，或失败原因、错误编号和操作编号。上方提示同步保留。失败不清空输入草稿；名称重复/超长按INPUT报告，不再笼统称作存储故障。长时间等待不提前报失败、不自动重发、不解除后台busy；可切到操作日志看当前阶段。

## 操作日志

侧边栏新增“操作日志”，显示最近500条本机管理员操作，可按结果筛选并按操作名称、错误码、操作编号搜索。进入页面及页面可见时每3秒刷新；读取日志本身不产生新日志。

- 覆盖本机令牌/倍率分组读取和发布、平台登录/授权保存、飞书连接/断开/凭据及绑定/策略操作、注册/倍率记录核对、令牌详情与密钥显示/复制等白名单入口。
- 记录操作开始时间、完成时间、耗时、结果、操作编号、错误类别和HTTP状态。倍率分组发布另外细分授权核验、读取平台分组、名称校验、账户复核、本机保存阶段。
- 不记录调用参数、别名、邮箱、用户ID、密码、密钥、凭据、Cookie、错误原文、堆栈或完整响应。记录“显示/复制密钥”动作不记录其内容。不同操作以独立上下文关联，异步并发不串日志。
- “完成”指该管理操作返回成功，不代替真实飞书在线或业务最终结果；“启动连接”完成后仍应看管理配置页。自动后台重连和飞书业务请求不在这份管理员点击日志中，分别看连接状态与对应业务记录。
- 中途退出后，未写入终态的操作显示“中断待核对”，不擅自判为失败，不自动重试。
- 日志从本版本运行后开始，旧操作不会补造。通过本机管理员窗口读取，不依赖仍有效的平台登录，客户窗口和非主页面调用被拒绝。

文件位于业务数据根 `%APPDATA%\CheapiKeyStudio\admin-operations.jsonl`。采用追加式写入和flush，最大4MB，不自动覆盖或删除。达到上限、损坏或写入失败时保留原件并提示，新记录仍在本次内存中，重启可能丢失；日志故障不会把已经成功的业务误报为失败，也不能替代权威业务账本。不要上传日志或整个业务数据目录到仓库。

## 验证

312项Node测试、52项隔离Electron检查、66份语法检查通过。包含日志重开、运行中/中断状态、并发阶段、秘密过滤、坏文件保留、内存上限、日志磁盘失败不改变业务结果；真实Electron验证慢请求反馈、按钮旁成功/失败、名称冲突INPUT、草稿保留、日志筛选、IPC权限和六栏目。已查看操作日志及保存区宽屏截图，原有窄屏回归通过。

全部测试使用合成资料，未替用户重复保存真实分组，也未创建/修改平台用户。历史无反馈的这次操作仅确认界面已显示成功，不能用新增日志追溯尚未记录的历史网络过程。

现场加载后已确认六栏目入口、原授权及飞书自动连接恢复，真实只读分组读取操作已持久写入日志；没有为了验收再次提交真实发布或业务修改。
